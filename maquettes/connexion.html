Comment la connexion marche

  1. Clic sur « Se connecter »

    Le navigateur va sur /api/strava/connect.

    serveur

  2. Strava demande ton accord

    Redirection avec un state aléatoire (cookie httpOnly).

  3. Retour sur /api/strava/callback

    Le code est échangé contre des tokens. Le secret client ne quitte jamais le serveur.

    serveur

  4. Tokens rangés dans Supabase

    Table sans lecture côté navigateur. Rafraîchis automatiquement avant expiration.

    serveur

  5. Synchro des activités

    upsert … on conflict (source, external_id) : jamais de doublon.

    serveur

Import GPX / FIT plan B

Dépose un fichier .gpx ou .fit, ou choisis-le.

Démo : le fichier reste dans ton navigateur. On calcule son empreinte SHA-256 ; la même empreinte deux fois est ignorée, comme le fera external_id côté base.

Côté serveur seulement

  • STRAVA_CLIENT_SECRET
  • Tokens d'accès et de rafraîchissement
  • SUPABASE_SERVICE_ROLE_KEY
  • Vérification du webhook

Le navigateur ne voit que l'URL Supabase et la clé publique, protégées par RLS.
